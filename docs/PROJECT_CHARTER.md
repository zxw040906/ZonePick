# ZonePick 项目章程

状态：初稿，待审阅。

本文记录项目已确认的方向和范围。标为「暂定」的内容是用于讨论的研发建议，详细需求和技术架构将在章程审阅后另行制定。

## 1. 项目背景与定位

ZonePick 是一个基于多麦克风阵列的目标区域语音增强与可视化仿真平台。它以空间区域作为拾音条件，让使用者配置多个说话人和麦克风阵列，提取目标区域内的语音，并对比不同算法在同一声学条件下的表现。

项目服务于硕士科研学习和算法工程实践，为 2029 届实习求职积累可展示的成果，并为毕业论文及潜在的学术论文提供可复核的实验依据。

## 2. 长期目标

- 建立从声学场景配置、阵列信号生成、目标区域语音提取到评价的完整实验流程。
- 在统一的场景、数据划分及评价协议下比较传统、混合和纯神经网络方法，记录各自的适用条件和失败案例。
- 通过浏览器展示实验条件和结果，使研究者能够复现结论，演示者能够直观说明区域和算法选择如何影响拾音效果。

## 3. 目标用户与应用场景

| 用户 | 应用场景 |
| --- | --- |
| 项目开发者及参与研究的学生 | 学习阵列信号处理，构建基线，训练模型并开展对照或消融实验 |
| 导师和科研合作者 | 核对实验设置与指标，复现实验，讨论结果及其局限 |
| 论文答辩、项目展示与实习面试的观众 | 观察区域、声源与阵列的空间关系，试听处理前后的音频，查看指标对比 |

## 4. 核心功能范围

1. **多说话人仿真**：配置说话人数量、声源位置、麦克风阵列和声学环境，生成多通道观测信号及评价所需的参考信号。
2. **目标区域拾音**：支持自定义空间区域，从阵列观测中提取区域内的目标语音，并评价区域外干扰的抑制效果。区域形状、边界判定和多个区内说话人时的输出定义待讨论。
3. **算法实验**：支持三条算法路线，并按统一条件运行和对比。
4. **浏览器可视化**：展示和配置场景，选择算法，试听音频，查看波形、频谱及指标。
5. **实验管理与评价**：保存实验配置与结果，支持模型训练、评价和复现。具体存储方案待选。

## 5. 算法技术路线

| 路线 | 研究方向 | 候选方法 |
| --- | --- | --- |
| 传统阵列信号处理 | 利用阵列几何与空间声学信息增强目标区域语音，建立对照基线 | 延时求和（DAS）、最小方差无失真响应（MVDR） |
| 神经网络与传统算法结合 | 由网络估计目标或干扰信息，再用传统阵列处理生成增强输出 | NN Mask + MVDR |
| 纯神经网络 | 将空间区域作为条件，由网络直接输出目标语音 | 区域编码方式、输入表示和网络架构待比较 |

三条路线均已确认纳入长期范围。表中方法用于说明研究方向，具体实现、训练数据与评价协议将在后续任务中确定。

## 6. 软件仿真与可视化

初期使用纯软件仿真，无需实际麦克风硬件。本地开发使用 WSL2 和 Python/PyTorch，后续可视训练规模评估学校 GPU 服务器。

浏览器界面需要展示声源、麦克风和目标区域的相对位置，支持区域配置、算法选择、处理前后的音频试听，以及波形、频谱和指标对比。对比结果应关联到同一场景和对应的运行配置。界面框架、服务接口及渲染方式待讨论。

## 7. 工程质量与实验可复现

- 记录代码提交、运行环境、依赖版本、数据来源与划分、随机种子、场景参数和算法配置。训练实验还应记录训练参数和检查点。
- 记录指标定义、参考信号及计算设置。在比较算法时固定场景、输入和评价口径，使差异可以追溯到所比较的变量。
- 保留从配置到结果的操作步骤，关联音频、指标及必要日志。记录跨设备或跨运行出现的已知数值差异。
- 随实现补充针对信号维度、区域边界及指标计算的测试，并用小型样例验证完整流程。

## 8. 研发流程与协作原则

- 章程审阅后，另行制定 PRD 和技术架构。影响范围、接口或实验口径的决定应记录依据及讨论结果。
- 当前阶段采用单人本地开发。经项目负责人明确授权，Codex 可直接提交并推送到 `main`。操作前检查工作区和远程分支状态，遇到未提交修改或远程冲突时停止。后续关键算法开发建议使用独立分支和指向 `main` 的 Pull Request，说明变更、验证结果及未解决问题，由维护者审查。提交应聚焦单一任务。
- 实验结论应能定位到配置、代码版本和产出。涉及音频数据或模型时，应记录来源与使用许可。

## 9. MVP 第一版目标（暂定）

用一个可配置的多说话人仿真场景打通「场景配置 → 多通道混合 → 区域拾音 → 浏览器试听与评价」流程。建议先验证一个区内说话人和至少一个区外干扰者的场景，由 DAS 作为首个候选基线，并与未增强输入对比。

建议验收方式是用已保存配置重新运行样例，在浏览器检查声源、阵列与区域的位置关系，试听输入和增强音频，查看至少一项定义明确的评价指标。区域几何、基线实现、指标及通过门槛由后续 PRD 确认。混合和纯神经网络方法列入后续阶段。
