# ZonePick 四区评测协议

输出固定为 FL、FR、RL、RR。每路输出与对应区域的独立参考比较。同一区域多名说话人按区域求和，固定标签参与打分，全程禁止输出重排。按场景 ID 配对比较 8、6、4、3、2 MIC，公开参考通道及物理位置。

参考候选包括增益后的干净语音、同一虚拟点的直达声或早期/完整混响、选定阵列各物理麦克风的区域混响分量。五种布局没有共同物理麦克风。由 B02、B04 和 B05 验证虚拟点、主监督目标及延迟约定。评测时使用统一预设对齐，禁止逐算法用真值搜索最有利的移位。测试集只用于最终评估，模型选择在验证集完成。Oracle 独立运行和报告。

| 口径 | 候选指标及报告约定 |
| --- | --- |
| 活跃区域 | 绝对 SI-SDR 和 SI-SDRi 同报，记录参考定义及未处理基线。候选指标还有多干扰 SIR、目标增益误差及目标保真。所有区外源均应计入，多参考 SIR/SAR 先验证投影及退化组处理，再冻结协议。 |
| 区域串扰 | 报告四区串扰矩阵。非线性模型使用明确的多参考分析协议，报告投影与尺度约定、空参考和共线处理。 |
| 空区域 | 单独报告残余能量及虚假激活率。有人但未说话的区间单列，零参考排除普通 SI-SDR。 |
| 感知质量 | STOI、ESTOI、PESQ。记录采样率、标准模式和不可评分样本。 |
| 资源与稳定性 | RTF、推理耗时、算法延迟、参数量、MACs、内存/显存峰值及失败率。记录硬件、预热、批大小与线程设置。 |
| 汇总 | 记录有效及失败的场景数、逐场景分布、分位数与必要置信区间。跨 MIC 比较用场景级配对差，并报告失败样本的处理方式。 |

B00 工作台用于单区域回归，B01 验证场景合同。B05 实现并验收统一批量评测后再进入 B06。
