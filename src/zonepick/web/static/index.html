1. 配置并运行 常规推理

提示：圆心（x, y）与指向高度共同决定 DAS 的指向点，算法不会读取真实声源位置。把圆心移到区内/外说话人互换，可观察增强效果变化。
自定义场景：以选定预设为模板，可修改场景 JSON（仅允许白名单字段）。保存后即可在上方选择并运行。

2. 位置预览 · 手动画区域

带坐标轴（单位 m）。二维可点选圆心 / 拖拽画圆 / 拖圆周改半径，与数字输入实时同步。
35° 可拖动滑块旋转观察三维空间中的阵列、声源与指向点（只读，区域绘制请用二维视图）
红点 = 声源，蓝点 = 麦克风，蓝色虚线圆 = 目标拾音区域。实测场景的几何在加载时由数据集解析（仅用于可视化，不参与推理）。
